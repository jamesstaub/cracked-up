The basics

You build sound by chaining nodes. A node makes sound (an oscillator, a sampler) or changes it (a filter, a gain). __() starts a chain; each method adds a node and connects the previous one to it. 

__().saw(110).lowpass(800).gain(0.3).to('main');

That is a sawtooth oscillator at 110 Hz, into a low-pass filter at 800 Hz, into a gain of 0.3, into the output. A chain you do not send anywhere makes no sound.

Give a node an id when you want to reach it later. Pass options as an object; a bare value sets the node's main parameter, so lowpass(800) is short for lowpass({ frequency: 800 }). 

__().saw({ id: 'bass', frequency: 55 })
  .lowpass({ id: 'filter', frequency: 400, q: 8 })
  .gain(0.3)
  .to('main');

Where sound goes: main

main is the engine's output. It is a bus: a named point where any number of chains are mixed together. The engine creates main for you and connects it to your speakers. It is the only bus that exists until you make another.

In the original Cracked library every chain ended with its own .dac() node. Here every chain ends at the one shared main, which gives a single place to set the overall level, and later to meter or record everything. 

__().sine(220).gain(0.2).to('main');
engine.bus('main').gain.set(0.5); // overall level

You can make more buses to group sounds, for example a shared effect. A new bus feeds main until you route it somewhere else. 

__.bus('drums').gain.set(0.8);
__().sampler({ id: 'kick', buffer: 'kick' }).to('drums');
__().sampler({ id: 'hat', buffer: 'hat' }).to('drums');
every(0.25, () => __('sampler').trigger());

Sending to a bus that does not exist is an error, so a mistyped name is caught at once.

to, connect and modulate

All three make a connection from the end of a chain. They differ in what they connect to.

Method Connects to A string means
.to('main') A bus The bus's name
.connect('#filter') The input of one or more existing nodes A selector that finds the nodes
.modulate('#filter', 'frequency') A parameter of existing nodes, so the signal moves that parameter A selector that finds the nodes

So .to('main') and .connect(engine.bus('main')) do the same thing. to exists because ending a chain at a bus is the common case, and because a string there is a bus name, while a string given to connect is a selector. 

// Two oscillators into one filter.
__().lowpass({ id: 'filter', frequency: 600 }).gain(0.2).to('main');
__().saw(110).connect('#filter');
__().square(165).connect('#filter');

// A slow sine moves the filter's cutoff by +/- 300 Hz.
__().sine(0.5).gain(300).modulate('#filter', 'frequency');

When something modulates a parameter, its signal is added to the parameter's own value. An oscillator swings between -1 and 1, so a gain after it sets how far the parameter moves.

Selecting nodes

__('selector') finds nodes you have already made and returns them as a selection. Whatever you call on a selection applies to every node in it.

Selector Finds
sampler Every node of that type
#kick The node with that id
.drums, .drums.loud Nodes with that class, or with all of several classes
[role=send], [solo] Nodes with a tag of that value, or with that tag at all
sine, saw Either
sampler:not(.muted) Samplers without the class
gain:nth(1) The second gain, counting from 0 in the order they were made
* Everything 
__().sampler({ id: 'kick', buffer: 'kick', class: 'drums' }).to('main');
__().sampler({ id: 'hat', buffer: 'hat', class: 'drums' }).to('main');

let n = 0;
every(0.25, () => {
  __(n++ % 2 ? '#hat' : '#kick').trigger();
});

Classes and tags are set when a node is made: { class: 'drums loud', tags: { role: 'send' } }.

Changing parameters

Every node has parameters, listed in the reference below. Each one has a base value: the value you set, and the one a slider would show.

Call Does
.set({ frequency: 800, q: 4 }) Sets base values
.frequency(800) The same, for one parameter. There is a setter for every parameter name
.ramp('frequency', 2000, { duration: 2 }) Glides the base value to a target over a number of seconds
.offset('frequency', 500, { duration: 0.1 }) Adds an amount on top of the base value for a while, then returns to it
.param('frequency').value Reads the base value 
__().saw(110).lowpass({ id: 'filter', frequency: 200, q: 6 }).gain(0.2).to('main');
__('#filter').ramp('frequency', 3000, { duration: 4 });

The one exception to the setter rule is a parameter called release (on the compressor): .release() already means "release the note", so that parameter is set with .set({ release: 0.2 }).

The minimum and maximum in the reference are the range a control would cover. They are not limits: you can set a gain of 300 when it is scaling a modulation.

Starting and stopping sounds

.trigger() starts a sound and .release() ends it. What that means depends on the node.

A sampler plays its buffer once per trigger. Each trigger is a new voice, so you never need to stop or rewind it before the next hit. Options given to trigger apply to that hit only. 

__().sampler({ id: 'hat', buffer: 'hat' }).to('main');
let n = 0;
every(0.125, () => {
  __('#hat').trigger({ speed: 1 + (n++ % 4) * 0.2, velocity: 0.6 });
});

An oscillator runs from the moment it is made and is heard straight away, as a drone. release() closes its gate and trigger() opens it. To make one that is silent until triggered, create it with gate: 'closed'. 

__().square({ id: 'blip', frequency: 660, gate: 'closed' }).gain(0.15).to('main');
every(0.5, () => __('#blip').trigger({ duration: 0.08 }));

Samplers and where their audio comes from

A sampler plays a buffer: a piece of recorded sound held in memory. The engine keeps a store of named buffers, engine.buffers, so the same sound is decoded once and shared by every sampler that uses it.

A sampler's buffer option accepts three things:

You pass What happens
A name already in the store, such as 'kick' That buffer is used
Any other string It is treated as a URL: the file is fetched, decoded, and stored under that URL. The sampler is silent until loading finishes. The server must allow requests from this page.
An AudioBuffer you made or decoded yourself It is used directly

In the live demo, 'kick', 'snare' and 'hat' are not files. The demo page generates them with a few lines of maths when audio starts and adds them to the store by name: 

engine.buffers.add('kick', audioBuffer);

A buffer can be cut into slices by giving it boundaries in seconds. A trigger can then play one slice by number. 

const kit = engine.buffers.get('snare');
kit.slices = [0, 0.03, 0.1, 0.25];
__().sampler({ id: 's', buffer: 'snare' }).to('main');
let n = 0;
every(0.2, () => __('#s').trigger({ slice: n++ }));

Time

Most calls take an optional at: the moment the change should happen, in seconds on the audio clock (engine.context.currentTime). Leave it out and the change happens now. Scheduled changes land on the exact sample. 

const now = engine.context.currentTime;
__().sine({ id: 'tone', frequency: 220 }).gain(0.2).to('main');
__('#tone').set({ frequency: 330 }, { at: now + 1 });
__('#tone').set({ frequency: 440 }, { at: now + 2 });

Sequencing (patterns, tempo, polyrhythms) belongs to the transport, which is not built yet. Until then the demo provides every(seconds, fn), a plain timer whose timing is loose. It is not part of the library.

Names available in the live demo

Name What it is
__ Starts a chain (__()) or selects nodes (__('selector')). Also __.bus('name')
engine The engine itself: engine.buffers, engine.context
every(seconds, fn) Temporary timer, provided by the demo page only
euclid(hits, steps, rotate) An evenly spread rhythm as an array of 0s and 1s
pitchToFreq, freqToPitch Convert between MIDI note numbers and Hz
scales(name), chords(name) Lists of semitone steps, such as scales('minor')
dbToGain Converts decibels to a gain factor

Each time the demo re-runs your code it starts from nothing: the nodes and timers from the previous run are removed once the new code has run without an error.

Options every node accepts

Option Meaning
id A name for the node, unique among the nodes made together. Select it with #id. Nodes without one get a generated id such as gain-0
class One or more class names separated by spaces. Select with .name
tags An object of extra labels, such as { role: 'send' }. Select with [role=send]
